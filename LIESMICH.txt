BOATSDOC
========

Startseite:   index.html
Rechner:      kalkulator.html?p=beispiel-marina
Backend:      partner.html   (Demo: demo@marina-schleibucht.de / demo1234)

Ohne Server (Doppelklick im Browser oder GitHub Pages) läuft alles als Demo,
die Daten bleiben dann nur im eigenen Browser.

Mit Server (echter Betrieb unter boatsdoc.com):
  node server/server.cjs
Einrichtung auf dem IONOS VPS: siehe deploy/ANLEITUNG.md

Sprachen: Deutsch, English, Svenska, Norsk, Dansk, Suomi

Zum Weitergeben den kompletten Ordner verschicken, nicht nur index.html.
